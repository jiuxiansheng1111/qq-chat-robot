# 随机故事

在 QQ 群里先 @ 机器人，也可以使用 `/随机故事`。微信私聊直接发命令即可。

```text
随机故事
随机故事 催泪 一个旧玩具等主人回家
帮我写个故事 幽默：社恐猫咪第一次参加聚会
生成故事 主题：迟到的信；风格：黑色幽默；提示词：邮差、老街、误会
```

可以给主题、情节、关键词和风格，也可以只发命令。支持“随机故事”“生成故事”“写个故事”“来个故事”。

有素材时，从素材中取一句短主题；没有素材时随机选主题。没指定风格时，会在搞笑、催泪、幽默、温馨、悬疑、奇幻等风格中随机选择。想指定其他风格，可以写 `风格：轻小说` 这样的短标签。

回复格式如下，正文目标长度约 400～700 字：

```text
主题：一个旧玩具等主人回家
风格：催泪

故事正文……
```

## 模型与发送

故事使用现有模型连接。在 AstrBot 中，使用当前会话的模型提供商和备用模型，不需要再填一份密钥。

每次创作只传本次素材和故事要求，不加入角色设定或聊天记忆，也不把故事命令当作成员的聊天风格样本。每群同时写一篇，全局最多两篇；继续遵守原来的用户、群限流。长回复按现有文本发送方式分段。

图片菜单的“聊天陪伴”里有故事入口，文字版菜单有完整用法。此功能只生成文字，不启动语音、翻唱或训练服务。
