通过未登录的公开播放接口取得参考 AAC 音轨，实际时长约 29.435 秒；用 `htdemucs_ft` 分离，再在 CPU 上测量。链接 1.8 秒起的人声 F0 中位数约 501 Hz，10–90% 分位约 424–741 Hz。它未能与本地第 60–85 秒源片段可靠对齐，不能直接根据两个片段的 F0 中位差确定移调量。
