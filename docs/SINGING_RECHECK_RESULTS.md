# 三语翻唱复验摘要

这份摘要只列质量指标，不含歌词、转写正文或本机文件位置。CER 来自 Whisper 对歌唱片段的识别，只作听辨参考，不能作为自动验收线。

## 可比范围

21 组 baseline/candidate 中有 7 组可作同源比较：全部是中文。两阶段保存的人声模型输入哈希与片段窗口都一致。

另外 14 组日语和英语不能据此判定训练效果。它们引用相同的歌曲和音频文件名，但 baseline 与 candidate 的声明窗口不同；逐项保存的 `vocal_before.wav` 输入哈希也不同。日语窗口从 23.173 秒变为 20 秒，英语从 20.44 秒变为 20 秒。不能用共享路径或相同的源 ASR 分数把它们说成同源。

源音频对照歌词的 CER 在两阶段都相同：中文 0.480、日语 0.360、英语 0.114。这个结果说明 ASR 本身对这些歌唱片段也有明显误差。

## 建议

- 保留已接受的 Murasame 500/B。该结果里 Murasame 中文 CER 从 .520 升至 .720；日语从 .320 升至 .620，但日语不具同源可比性。不要据这轮 candidate 覆盖已接受权重。
- 可先群听 aimisi 中文与 lena 中文 candidate；它们是本轮可比中文里 CER 更低的候选。听后再决定是否保留。
- Mako 日英 candidate CER 线索较好，分别为 .380 与 .152；lena 英语为 .182。它们可以作为试听样本，但不能宣称比 baseline 训练效果好，因为对应输入音频不同。
- 不因训练 loss 下降而机械采用更多步数的权重。对其余音色先保留当前权重，等同源片段和人工听辨结果再决定。
