# AstrBot 接入检查

检查日期：2026-10-04。固定 AstrBot 4.28.2，Windows 独立 Python 3.12.15。

## 已确认

- QQ 反向 WebSocket 已实际连通，旧 8000 webhook 与旧看门狗已停止；HTTP API、网易云桥与 TTS 保留。
- 本项目插件与画境拾珍已加载。随机图片短句交给图片插件，角色图鉴、收藏、原角色和已接受音色继续复用。
- 原启动入口读取私有启动模式，迁移后会启动 AstrBot；启动、重复启动及停止经过真实检查，只处理归属已验证的 AstrBot 进程。
- 微信默认禁用预设可扫码登录，配置重建保留账号与登录态。私聊、群聊、不同平台和账号的回复路由做了隔离；个人微信不支持发语音，翻唱改发附件。
- 菜单图片已检查文字、分组和千恋万花背景，图鉴与短版/整首翻唱均保留。猫图按内容去重，以 GIPHY 的 GIF 为主。
- 英文说明注释已改成简短中文，Python 算法 AST 与原文件核对一致；PowerShell/VBS 的非注释内容也核对一致。
