# 大肥鱼一起玩

在已开启的 QQ 群或私聊里直接说游戏名和邀请。群里的「我也来」「谁报名了」「取消报名」会更新这次聊天的约局，雀魂和炉石的名单分别保留一小时。

## Minecraft Java

说「大肥鱼，一起玩 Minecraft」。首次由主人回复服务器地址和端口。地址存入项目的本地文件 `data/game-companion.json`。正式服务器使用大肥鱼自己的正版 Java 账号。

在运行机器人的电脑打开[大肥鱼账号管理](http://127.0.0.1:6190/accounts)，选择 Minecraft 的「登录或验证」。页面给出设备码后，到微软页面完成授权。验证通过后即可设置服务器地址，这一步也可以在 QQ 私聊完成。已有服务器地址时，仍可从项目根目录用原来的终端入口授权。

    node integrations/minecraft-player/player.cjs --login

进服后，大肥鱼默认自己玩。她会找附近的树、捡原木、准备工作台和木镐，再找石料和煤。有合适食物时会自己吃，做完几件事也会主动休息。说「帮我收集木头」可以指定目标，「你在干嘛」「背包里有什么」会查询当前角色。说「停一下」后，她会留在原地歇一会儿，然后自行继续。说「退服」会结束这次联机。

需要她跟着某位玩家时可以说「跟随 Alex」，目标要出现在附近。路径规划会避开需要拆方块和垫方块的路线。要求客户端模组握手的 Forge 整合包需要在对应服务器验证。安装依赖时在 `integrations/minecraft-player` 下运行 `npm ci`，使用 Node.js 22 或更新版本。

## Steam

主人可私聊说「大肥鱼的 Steam 账号设为 你的17位SteamID」，并让同一个账号登录本机 Steam 客户端。发 Steam 好友邀请里的大厅链接，回复「好」后大肥鱼才会转交给 Steam。游戏自己负责加入席位和游戏中的操作。[Valve 大厅接口](https://partner.steamgames.com/doc/api/ISteamMatchmaking)

也可以在[本机账号管理](http://127.0.0.1:6190/accounts)绑定或解除 SteamID，并打开 Steam 客户端。管理页会核对客户端是否实际登录了大肥鱼绑定的账号。雀魂、网易云、ChatGPT 和 B 站视频创作的账号入口也在同一页。

若要在 QQ 问「进房了吗」，可以把自己的 Steam Web API 用户密钥写进本机配置的 `steam.web_api_key`。账号或游戏公开了大厅号时，大肥鱼才会确认自己是否在指定大厅。[Valve 账号状态接口](https://partner.steamgames.com/doc/webapi/isteamuser)

## 雀魂和炉石

「雀魂三缺一，房号 12345」可以组织友人场。「雀魂练何切」会发一副四麻手牌。也可自带 14 张闭门手牌，如「雀魂何切 123457m345p678s11z」，再回「切 1z」。牌效按已知手牌计算。发官方牌谱分享链接会转给原有复盘功能，完整复盘沿用其支持的普通四人东风、半庄规则。友人场可以由房主加官方电脑补位。[雀魂官方入门指南](https://mahjongsoul.com/startguide/)

「一起打炉石」可以约战，接着说「狂野20牧」或贴卡组代码会查询原有卡组资料。好友挑战由玩家在战网发起，大肥鱼在 QQ 帮玩家备战。暴雪禁止第三方程序代打对局。[暴雪对自动对战的说明](https://hearthstone.blizzard.com/en-us/news/16481223)
