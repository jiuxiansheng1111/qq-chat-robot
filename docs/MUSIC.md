# 网易云点歌、选歌与歌词

## 点歌

```text
@机器人 点歌 春泥棒
@机器人 点歌 中文别名 春泥棒
@机器人 点歌 English alias Song title
/点歌 歌手名 歌名
/music 歌名
```

只有明确使用 `点歌`、`/点歌`、`/music`、`来首` 或音乐用途的 `播放` 前缀时才进入点歌；普通聊天不会触发。匹配只使用网易云返回的歌名、歌手和别名，不调用 LLM 猜歌名；中文、英文或日文歌手别名只有在网易云搜索结果中确实收录时才可匹配。上面的别名示例仅说明输入格式，不保证特定歌曲有对应别名。搜索命中唯一且精确的歌曲时会直接发送；否则最多列出 5 个候选，回复 `选歌 2` 选择第二首。候选保留 120 秒，并按机器人账号、会话和成员隔离；`取消选歌` 可清除自己的候选。

## 歌词与歌单

```text
@机器人 查歌词 春泥棒
@机器人 查歌词 2
@机器人 歌单 123456789
@机器人 歌单 https://music.163.com/playlist?id=123456789
```

`查歌词 歌名` 搜索歌词；`查歌词 2` 查询当前候选中的第二首。歌词图会清除 LRC 时间标签和元数据并分页；图片不可用时会回退为完整文字。候选需要先确认。歌单保留原顺序，用户界面只展示公开歌单的前 5 首并标出总曲数；这不表示服务端只读取了 5 首。歌单接口响应超过 1 MiB 时会提示读取失败。

歌单接受 1–20 位数字 ID，或 `music.163.com` 上的 HTTPS 歌单链接。私有或无法读取的歌单会提示重试；此功能只展示候选，不代表支持整份歌单播放。选歌、按编号查歌词和取消可直接发送命令，无需再次 @；只发数字不会触发。

## QQ 卡片与私聊

QQ群使用 OneBot 网易云音乐卡片段：

```json
{"type":"music","data":{"type":"163","id":"歌曲ID"}}
```

卡片发送失败时会回退为歌曲名、歌手和网易云页面链接。QQ 客户端也可能在接口成功后仍无法播放卡片，机器人无法确认接收端是否可播。微信私聊和群聊发送歌曲名、歌手和页面链接文本；当前没有新增 QQ 私聊点歌入口。点歌流程不下载整首音频。

## 网易云账号与配置

点歌搜索、歌词和公开歌单不需要网易云登录。可选的本机会员桥默认关闭，只供翻唱音源使用；翻唱使用独立开关，点歌不会自动启动语音或 GPU 服务。如需配置会员桥，运行 `scripts/start_netease_member.ps1`，在本机打开 `http://127.0.0.1:3010/login` 扫码，并按 [翻唱说明](SINGING.md) 配置 `NETEASE_MEMBER_ENABLED=true`。登录数据保存在被 Git 忽略的本地目录；不要提交或分享账号数据。

可在 `.env` 中调整公开搜索接口与超时：

```dotenv
NETEASE_MUSIC_API_URL=https://music.163.com/api/search/get
MUSIC_TIMEOUT_SECONDS=10
MUSIC_SEARCH_LIMIT=8
```

网易云网页搜索接口不是官方开发者 API，平台调整时可能暂时不可用。会员桥凭据只留在本机，不传给候选卡片或歌词渲染代码。
