# 音乐点歌

## 使用方法

```text
@机器人 点歌 ZUTOMAYO TAIDADA
@机器人 点歌 Yorushika Sunny
/点歌 歌手名 歌名
```

机器人通过 Deezer 公开搜索接口查找歌曲，并向 NapCat 发送 OneBot `custom music` 卡片。
卡片包含歌名、歌手、封面、Deezer 页面和约 30 秒试听，通常可在 QQ 群中直接点击播放。
该功能不需要新增 API Key。

## 曲库与版权边界

Deezer 覆盖多语种商业曲库，实测能搜索 ZUTOMAYO 和 Yorushika，但结果受地区授权、
曲名写法和平台收录影响，不能保证所有歌曲都有试听。优先使用“歌手名 + 歌名”能提高命中率。

机器人不会抓取或转发完整版权歌曲。完整歌曲需要用户点击卡片进入持牌平台，并按平台所在地区、
账号及订阅权限播放。若未来要加入 QQ 音乐、网易云或 Spotify，应使用对应平台授权接口和账号权限，
不要接入来源不明的音频解析、盗链或下载 API。

## 故障排查

- 显示“没找到”：换用罗马字、英文艺名或同时输入歌手和歌名。
- 音乐卡片发送失败：机器人自动降级为试听 URL 与 Deezer 歌曲页面。
- 搜索超时：检查服务器能否访问 `https://api.deezer.com`。
- 卡片有封面但不能播放：可能是试听链接在当前地区不可用，或 NapCat/QQ 版本不兼容。
