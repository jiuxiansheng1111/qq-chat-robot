# 音乐点歌

## 使用方法

```text
@机器人 点歌 春泥棒
@机器人 点歌 夜鹿 春泥棒
@机器人 点歌 yorushika 春泥棒
@机器人 点歌 ZUTOMAYO TAIDADA
/点歌 歌手名 歌名
```

只有明确出现 `点歌`、`/点歌`、`/music`、`来首` 或 `播放` 前缀时才进入音乐功能；普通的
`@机器人 歌名` 仍然是日常 AI 对话。歌名搜索不区分英文字母大小写，歌手名可以使用中文别名、英文或日文。

## 搜索与选曲策略

机器人优先调用网易云搜索接口，然后按照以下规则固定选曲：

1. 整串搜索优先匹配歌手和歌名。
2. 如果输入类似 `夜鹿 春泥棒`、`yorushika 春泥棒`，会从最长的歌名后缀重试 `春泥棒`。
3. 歌名要求规范化后完全一致。
4. 默认过滤 Cover、Remix、KTV、伴奏、纯音乐、钢琴和吉他版本。
5. 多个原曲都符合时按稳定的歌曲 ID 选择，避免同一句话每次跳到不同版本。
6. 遇到日文假名、韩文、俄文等外语拼写且直接搜索无法确认时，会先生成中文/罗马字等价提示，联网核对原唱后再用标准艺人名和歌名回查网易云；原始输入不会被覆盖。

例如 `@机器人 点歌 夜鹿 春泥棒` 会稳定选择网易云中的 `ヨルシカ - 春泥棒`，不会因为中文别名
没有出现在歌手字段里而退回到随机翻唱。

## 消息发送与降级

首选 OneBot 原生音乐段：

```json
{"type":"music","data":{"type":"163","id":"歌曲ID"}}
```

如果 NapCat 或 QQ 无法发送网易云卡片，机器人会降级为自定义音乐卡片，再失败则发送网易云歌曲页面链接。
机器人不会下载或重新分发完整版权音频。

由于 QQ 音乐卡片依赖 NapCat 的外部签名服务，即使发送接口返回成功，客户端也可能无法直接播放。
机器人会在卡片后附带网易云页面链接，保证至少可以点击进入持牌平台播放；程序无法可靠检测接收端卡片是否可播。

## 配置

`.env` 中可以修改：

```dotenv
NETEASE_MUSIC_API_URL=https://music.163.com/api/search/get
MUSIC_TIMEOUT_SECONDS=10
MUSIC_SEARCH_LIMIT=8
```

当前网易云搜索入口是非官方网页接口，不需要 API Key，但平台调整接口时可能暂时不可用。若需要更稳定的生产部署，
可以把 `NETEASE_MUSIC_API_URL` 指向自己部署、兼容该搜索格式的网易云 API 服务。

## 故障排查

- 显示“没有确认到可靠的原唱”：换成 `歌手名 + 歌名`，或确认网易云确实收录原曲。
- 显示“点歌服务暂时不可用”：检查服务器网络、网易云接口可访问性和 `MUSIC_TIMEOUT_SECONDS`。
- 发送卡片失败：确认 NapCat 版本支持 OneBot `music` 段；机器人会自动降级为页面链接。
- 结果仍不准确：在点歌后面同时输入歌手、标题，避免只输入过于常见的单字歌名。
