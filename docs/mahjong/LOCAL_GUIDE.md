# 日麻攻防与场况本地解析

适用于四人立直麻将的学习与牌谱复盘。阅读顺序是：先认牌形，再比较进攻路线，最后把防守与点差放进去。正文可以离线独立阅读；`m／p／s`分别表示万／筒／索，东、白、发等直接写汉字。例子只使用决策当时能看见的信息。

## 一 先分清牌形与能否和牌

通常和牌结构是四组面子加一对雀头；面子为同花色顺子或同牌刻子。七对子、国士无双另算。听牌是再来一张便能完成和牌结构；一向听是还差一步进入听牌，依此类推。

| 局部形 | 补入什么 | 补入后的结构 |
|---|---|---|
| 两面`34` | `2／5` | `234／345` |
| 坎张`35` | `4` | `345` |
| 边张`12` | `3` | `123`；`89`同理等`7` |
| 两坎`135` | `2／4` | `123＋5／1＋345`，仍剩一张 |
| 五连形`34567` | `2／5／8` | `234＋567／345＋567／345＋678` |

两坎共用中间的3，不能当作两个独立搭子；五连形也只是整手的一部分。**原创整手示例：**`34567m 123p 789s 东东`，共十三张，其余部分已是两面子加雀头，因此结构上听`2／5／8m`。若摸到`1m`，切`1m`保留三面听；切`7m`后为`13456m`，只听`2m`。后者结构较窄，但若`1m`危险、`7m`安全，防守可能改变选择。

结构完成还不等于能荣和：须有役且不受振听禁止。上述牌可以通过门清立直取得役，不能凭宝牌直接和牌；宝牌加翻但不是役。振听不允许荣和，但仍可合法自摸。比较听牌时，应先确认规则资格，再比枚数、打点与危险度。

## 二 牌效要算受入也要算后续价值

受入是能推进向听数的牌；改良则可能暂不降向听，却让以后更容易形成好形或高打点。比较切牌通常先看向听，再列受入，最后检查听牌质量、有效役、打点和安全代价。同为一向听，不代表等价。

某牌的未见数等于四张减去当时已知的不同实体牌。自己的手牌、牌河、副露、杠与公开指示牌都要计入；被鸣走的弃牌不能重复扣除，红五和普通五合计仍是四张。**未见牌可能在别人手里或王牌中，不能直接叫作山里剩余牌。**

条件例：两条路线同为一向听，一条受入较多但常留下坎张，另一条少一些却能留下未见枚数充足的两面。无威胁、还来得及发展时，后一条可能更值得保留；急需先听、两面受入已枯，或前者有明显打点优势时，结论可能反转。速度的优点是更早争和，保留改良的优点是提高后续质量；不能用其中一项替代整手比较。

## 三 好形率不是看起来能碰几张

好形率关注“走过不同进张分支以后，有多大机会以好形听牌”，与当前受入量不是一回事。固定一个坎张后，其他部件无论摸成还是碰成，都可能只剩这个坎张；保留另一条进路，则可能让最终两面听出现得更多。

做题时画两列：每一种进张是什么、进张后最终听什么。再比较这些等待的未见枚数、场况与打点。**不要把四种好形分支、两种愚形分支直接说成好形率三分之二**：各分支未见枚数不同，摸牌与鸣牌机会也不等权。

如果碰一次就能形成有役、枚数充足的听牌，眼前速度可能压过未来改良；若碰后仍远、且把弱坎张固定下来，不碰的价值会升高。好形也并非必然好和：两面两侧都很少，未必胜过尚有多张未见、容易被打出的愚形。

## 四 孤张2与役牌要看整手路线

孤张`2`能靠`1／3／4`等形成有用搭子，一般具有形状发展价值；役牌重叠后可形成对子、争取碰成刻子取得役。前者偏向改良，后者可能打开副露与打点路线，不能固定排序。

原牌例十三张为`1123489m 89p 28s 白白`，本巡摸入`发`，共十四张。现在比较舍`2s`与舍发：即使保留`2s`后摸到`3s`，也只能替换`89m／89p`中的一组，不能同时消除两组边张，另一组仍易成为最终愚形。若原先只有低打点，而留发重叠后有机会走白、发叠加混一色，留发可能更有价值。代价是发不重叠时进展慢，染手也会牺牲别的花色。

无需图片也可按上述十四张牌复现这个比较。它说明应考虑整手收益，不代表当前就已保证能做成满贯。

反过来，若手里大多是顺子、两面，牌值已经够用，留下`2s`的自然改良常比勉强追役牌更合适。关键是“这张牌改善了整手什么”，不是后来恰好摸到被舍牌的邻张就判前一步错误。

## 五 现物、筋、壁分别能证明什么

**现物针对具体对手。** A曾弃过的牌种，对A的荣和安全，因为若属于A当前等待，A就受舍牌振听限制；被别人鸣走的历史弃牌也算。A立直后，别人打出而A未和的牌也可作为对A的安全依据。非立直者的过水只产生相应的暂时振听窗口，不能长期沿用。对A安全，不代表对B、C安全。

**筋只排除对应两面。** 若`4m`是A的现物，`1m`不会命中A的`23m→1／4m`，`7m`不会命中`56m→4／7m`；但`7m`仍可能命中`68m`坎张，`1m`仍可能命中单骑或双碰。反过来，仅`1m`安全不能把`4m`当成完整双筋：还要`7m`也有安全依据，才排除`4m`的两条基本两面路线；仍不排除坎张、单骑、双碰。

**壁排除物理上不可能的搭子。** 四张`3m`全部已知，别人不能再在暗手中持有`13m／23m／34m`，于是`1m／2m`的顺子等待路线被排除；单骑、双碰仍可能，`1m`还须留意国士。只有三张可见叫one-chance，第四张可能恰在危险家手里，不能当绝对安全。

弃和时通常优先寻找对主要威胁的现物；没有现物，再结合筋、壁、可见枚数与役路线比较。筋保留的风险较多，壁也不是通行证。若两家同时进攻，必须逐家核对，不能把各自的安全结论混用。

## 六 弱牌提前留退路

弱牌是离听牌远、改良有限、和了也不值多少的牌。为了一点边缘受入把安全资源全打光，遇到立直后就可能被迫连续冒险；提前保留退路，是用一部分速度换取撤退能力。

条件例：低价值三向听，手中有数张对当前主要威胁较安全的牌，可以先保留；真正进张、接近有价值听牌后，再重新分配进攻与防守牌。所谓“几向听留几张安”，适合提醒弱牌别贪，并非必须照抄的配额。

保留孤张改良的好处是手牌仍有发展，缺点是威胁来临时可能难切；保留安全牌的好处是可逐巡撤退，缺点是降低速度。字牌未经牌河与枚数核对也不自动安全；只防一家、没有考虑另一家的“安牌库存”同样可能失效。

## 七 立直与默听比较低目和代价

立直提供役与打点提升的机会，也约束以后换牌和弃和，并可能让对手收紧。默听保留改良、转守和隐蔽性，但可能少拿打点；没有其他役的等待，也不能默听荣和。

原牌例十三张为`3m 4m 赤5m 5m 5m／34p／455s／发发发`，摸入`3s`。切一张`5s`后可拆成`345m＋55m雀头＋34p＋345s＋发刻子`，听`2／5p`；`5p`完成三色，`2p`不完成。原牌例约十五巡，低目默听只有发与宝牌一，门清荣和约2600点。尚无明显对手进攻信号时，立直仍值得重视，因为两侧都能增值，不能只因剩余巡数少或“高目已够好”就自动默听。

若默听低目已经满足所需点数、有人强烈进攻、需要保留弃和，或者中后巡高目一侧确实更容易出现，默听更有吸引力。反之，高目本来难出，默听可能只收到低目。比较时分别列低目、高目、自摸、流局以及放铳风险，不把晚巡设成一刀切的默听开关，也不把偶然和到高目当作选择最优的证明。

## 八 领先时副露要计算失去的防守牌

副露能加速，但会固定面子、减少手中可选弃牌；还可能失去门清役或使部分役降翻。大幅领先时，赢一小牌的额外收益可能有限，而一次大放铳会严重损害名次。

条件例：南场大一位，先碰无役的西，再等待后付白，只为做低打点；若西本可作为防守资源，连续副露就可能换来“没听牌又没退路”。可以不碰，继续安全改良；也可先碰白取得役，并尽量让下一次副露直接形成好形听牌。西是否安全仍须逐家检查，不能只按牌名认定。

不碰保留弹性但可能拖慢结束本局；碰牌若能迅速和牌，也能阻止别人做大牌。东一平场、有红宝牌、碰后接近好形听牌时，积极副露可能更合理。“领先少冒险”不等于“领先禁止副露”。

## 九 杠要算全桌收益

本节为通用牌理补充。开杠可能带来岭上摸牌及新宝牌，但新宝牌也会增强他家；自己的加点只有成功和牌才兑现。原本门清时，大明杠会破坏门清；加杠还要面对抢杠风险，立直后暗杠须满足本桌规则限制。

条件例：自己已有高价值好形听牌，别人尚无明确威胁，开杠的额外机会值得比较；若大幅领先、自己远未听而别人已经立直，增加全桌打点波动常不合目标。不开杠保留原结构和较低波动，代价是放弃岭上与加点机会；不能为“已经凑齐四张”而自动杠，更不能把岭上和牌当保证。暗杠、加杠与大明杠的收益和限制应分开判断。

## 十 早中晚巡都要随证据更新

巡目影响剩余机会，但不是独立命令。早巡远手尚可发展，一旦有人立直仍须押引；晚巡远手追赶机会少，低价值连续冒险更难回本，但高价值听牌或末局逆转需求仍可支持进攻。

| 可见信息 | 能支持的判断 | 不能推出的结论 |
|---|---|---|
| 立直 | 已听牌，威胁明确 | 唯一等待或确定打点 |
| 多副露及明示宝牌 | 速度、役与价值有线索 | 必定听牌 |
| 手切与摸切次序 | 比较做牌路线是否合理 | 手切必降向听，摸切必听牌 |
| 某花色偏少、早切外侧 | 调整候选牌型的可信程度 | 暗手必有某张牌 |

自己从远手推进到好形一向听，或摸到多家安全牌，都应重算押引。继续进攻争取收益，但要支付当巡与后续危险牌的成本；撤退放弃和牌，却避免让一副弱牌不断追加风险。缺少巡目、点差或手切标记时，应保留“未知”。

## 十一 点棒收益、顺位收益与流局必须分开

东一平场可以更重视积累点数；南四则要计算哪种结果真正改变名次。先列庄家、各家分数、本场、供托、终局与延长规则，再比较自己和牌、别人和牌和流局。

荒牌流局的听牌料常被称为“罚符”，**不是违规罚分，也不是和牌打点**。常见四麻采用下表；部分人听牌时，共转移3000点，具体仍以本桌规则为准。

| 听牌人数 | 每位听牌者 | 每位未听者 |
|---|---|---|
| 0 | 不适用 | 0 |
| 1 | ＋3000 | －1000 |
| 2 | ＋1500 | －1500 |
| 3 | ＋1000 | －3000 |
| 4 | 0 | 不适用 |

立直棒与连庄另按规则处理，不能保证“立直必收三千”。为了争听牌要打危险牌时，还须比较放铳损失，不能把听牌料当免费收益。

**原创条件例：**南四零本场、无供托，我46000，B30000，庄家C14000，D10000；假设非庄D和牌即可终局。若我付给D1000，结算为45000、30000、14000、11000，仍是一位。极少数情况下，主动让可接受的小牌结束比赛，可能优于让庄家继续争和。

这只是条件计算，不证明当时能准确识别“只需付一千”的牌。隐藏宝牌、其他役、别家的荣和及终局规则都可能推翻判断。替代方案是弃和保护点差，或自己安全争和；前者可能让庄家连庄，后者可能需要冒险。所谓有意喂牌或小额放铳，只能是依公开信息、为自己最终顺位作出的独立选择，不涉及约定、串通或场外信息；无法可靠限制坏结果时，不应照做。

## 十二 高级读牌是比较解释而非看穿暗手

把牌河顺序、手切摸切、可见枚数、宝牌取舍与役种动机组合起来，可以调整某种等待的可信程度。例如连续舍去中张却保留边张路线，可能与全带幺、三色等目标相容，但也可能是进张顺序或别的牌形造成。

可按五步练习：先写已知事实；提出至少两种候选解释；检查每种解释与舍牌顺序是否矛盾；比较剩余等待及打点风险；最后决定当下哪张更可接受。没有可靠现物时，具体证据有时会让某张筋牌比无筋牌更可疑；这不推翻筋的基础逻辑，也不代表无筋普遍安全。

原截图为公开手牌后的复盘验证；相邻讲解确认对手实际听坎二万。它验证此前判断，不代表实战可见暗手，也不能把模糊牌面猜成完整手牌。

高级读牌的优点是利用额外证据，缺点是容易过度假设对手打法。新手有可靠现物时，不必为了“读中”而放弃安全牌。未校准的模型或经验不能生成精确放铳百分比；事后公开的暗手只用于验证，不能倒灌成当时已经知道的信息。

## 复盘时直接填写

**当时事实 → 候选动作 → 向听与未见受入 → 最终形状和役／打点 → 对三家分别的风险 → 点差目标 → 建议与替代方案 → 哪些新信息会改变结论。**

先评价决策，再记录结果。一次放铳不必然表示选择差，一次通过也不证明牌安全。
