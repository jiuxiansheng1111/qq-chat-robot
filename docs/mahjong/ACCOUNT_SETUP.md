# 雀魂账号与整场牌谱

运行 AstrBot 后，打开 `http://127.0.0.1:6190/`，或双击项目里的 `雀魂账号设置.bat`。

1. 点击「打开雀魂官网 / 注册」，自行完成国服注册、首次登录和验证码。
2. 回到设置页，填写国服账号密码，点击「保存并验证」。只有官方登录成功后才替换已保存的账号。
3. 保留「收到牌谱分析请求时，在这台电脑打开对应的雀魂页面」，就会在默认浏览器打开牌谱。浏览器登录状态由官网管理；后台读取使用单独保存的账号。
4. 私聊机器人，或在已开启牌谱分析的群里 @机器人，发送 `雀魂分析 牌谱链接`。

例如：`雀魂分析 https://game.maj-soul.com/1/?paipu=你的完整分享参数`。保留链接全部参数，可以自动识别分享者视角。没有视角时，补 `座位=东`、`座位=南`、`座位=西` 或 `座位=北`，指的是开局座位。

后台通过官方登录和牌谱读取接口取得整场事件，再逐局分析。浏览器是否显示完毕不影响后台读取。自动打开有一分钟间隔，连续请求不会反复弹出网页；读取任务串行执行。登录、验证或读取失败会直接返回原因，不会要求用截图冒充整场牌谱。

登录错误 151 表示客户端版本或连接参数被拒绝，不能据此断定账号未注册或密码错误。新版接入从官方 Unity 资源包读取当前资源版本，分别填写资源版、程序包版和 `WebGL_2022-` 客户端标识，并在登录前完成官方路由握手。版本解析失败时停止登录，不回退到旧版 `web-` 参数。协议依据：[登录版本字段](https://github.com/happy-shine/majsoul-autopilot/blob/main/crates/protocol/src/login.rs)、[路由握手字段](https://github.com/happy-shine/majsoul-autopilot/blob/main/crates/protocol/src/routes.rs)。

当前支持已结束的标准匹配四人东风、半庄。三麻、活动规则、友人房和赛事自定义规则暂不接入；缺局、缺结算、未知事件或点数不连续会停止分析。报告包含各局结果、点数变化和已有规则引擎筛出的关键决策；这不是 Mortal 一类训练模型的整场评分。AI 教学固定使用 GPT-6 Luna（`gpt-6-luna`），复用机器人已连接的 ChatGPT 订阅授权，只接收匿名决策片段，每局（含本场）优先挑选一个重要选择，短牌谱再补足到四个节点，最多覆盖三十二局；失败保留本地规则结果，不转给智谱或其他备用模型。可加 `AI=关闭` 停用。收到报告编号后，可用 `牌谱分析 详情 编号 节点号` 或 `牌谱分析 导出 编号` 查看报告。

默认回复发送文字摘要和逐局 JPG 图文卡片：每局优先选可比较的实际舍牌，展示当时手牌、具体出牌、候选建议、保留牌、向听与未见有效牌对照、当时顺位/点差/威胁和 Luna 攻守计划。建议与实际不同不自动等同于错误。没有可用 AI 解释的节点明确标为本地牌效候选，完整逐巡表仍可导出。QQ 私聊和群聊均支持；图片生成失败自动分段发完整文字。图片使用本地字体和牌张数据排版，不调用生图 API。

原生 AstrBot 入口在接管事件后通过 `event.send` 完成全部回复，避免 `stop_event` 后 `yield` 被调度器中断。处理期间每分钟更新进度；整场分析最多等待十二分钟，超时会取消分析并明确回复。图片渲染和单条发送分别限制三十秒；图片发送失败会补发文字版。可用 AstrBot 自带 Python 运行 `tests/mahjong_runtime_probe.py` 验证真实调度器和 OneBot 图片封装，使用模拟传输，不发送真实 QQ 消息。

模型请求采用 Responses 格式、低推理强度和 JSON 输出，须收到完整响应且返回型号为 `gpt-6-luna` 才接受教学内容。单节点最多等待 45 秒，整次 AI 教学最多 600 秒。模型依据：[OpenAI Docs · GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)。

账号凭据加密保存在 `data/mahjong/account/`，Windows 使用当前用户的 DPAPI；不会写入聊天模型提示词、QQ 消息或普通配置文件。页面只监听本机 `127.0.0.1:6190`，支持清除账号。第三方扫码登录的账号需要先在官方客户端绑定可用的账号密码。

测试覆盖旧版及新版二进制结构、全局转换、立直与暗杠、缺失数据拒绝、凭据保存、表单校验和 QQ 私聊/群聊路由。自动测试中的雀魂对局是合成样例；真实账号登录和实际分享牌谱需在管理员填写账号后验证。
