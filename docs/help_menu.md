# 帮助菜单

`app.services.help_menu` 提供聊天机器人菜单图片、文字菜单和文字版请求识别。主程序接入时，收到普通帮助命令先调用 `render_help_menu(settings)` 并将返回值作为 OneBot 图片发送；只有 `is_text_menu_request(text)` 为真时，才改发 `concise_text_menu()`。

## API

- `await render_help_menu(settings) -> str`：在线程中生成或读取缓存图片，返回 `base64://...`。成品宽 1080 像素、高度至少 1480 像素，内容较多时会继续增高；编码结果不超过 4 MiB。
- `concise_text_menu() -> str`：返回按六个模块分组的简明文字菜单。
- `is_text_menu_request(text) -> bool`：识别文字菜单命令和短自然请求，例如“给我看看文字菜单”。
- `is_help_menu_request(text) -> bool`：识别图片菜单命令和短自然请求，例如“给我看看菜单”；文字菜单请求优先返回 False。
- `normalize_menu_intent(text) -> str`：供主路由对明确 @ 或 slash 的输入调用，将不超过 40 字的短请求规范为现有命令。原命令和带参数查询保持不变；否定表达及较长聊天原样返回。

图片按 Pillow 绘制，使用白色半透明圆角卡片和大字号中文。优先加载 Windows 微软雅黑，其余系统尝试苹方、思源黑体、文泉驿等字体。找不到可用中文字体时会抛出易读的中文错误，不会静默输出方框字。

## 背景与缓存

`assets/help-menu-background.png` 是淡化后的千恋万花七角色合照底图；也可通过 `settings.help_menu_background_path` 指定背景路径。背景文件缺失或无法读取时会改用柔和的浅薄荷色代码渐变底图。渲染器不再淡化或模糊背景，只按画布比例缩放并叠加文字卡片。

生成的 PNG 缓存在 `data/help_menu/`。仓库已忽略 `data/`；缓存名包含背景文件状态和菜单内容摘要，菜单或背景更新后会生成新的缓存文件。图片绘制、编码和磁盘读写都在 `asyncio.to_thread` 中执行，不会阻塞事件循环。

## 图片文案

基础菜单按聊天陪伴、语音翻唱、点歌视频、实用工具、互动小游戏、管理六组展示，每组不超过三条示例；AstrBot 统一菜单还会加入原生命令和已启用插件功能。聊天陪伴组提供随机故事命令，主题、情节和风格都可省略；文字菜单也说明微信私聊可直接发送。互动小游戏卡片明确提供“@我 图鉴 / 角色图鉴”，文字菜单还展示“@我 角色图鉴 捷德（也可换成‘雷姆’）”的查询示例。翻唱卡片列出选角色、约 20 秒片段和整首分段发送；管理员命令仅作简短提示。

## 自然短句与命令核对

“来一个随机猫图”“给我猫咪动图”会规范成随机猫命令；“来段翻唱”会转成片段翻唱命令。故事可用“@我 随机故事 催泪 一个旧玩具等主人回家”或“@我 随机故事 主题：校园回忆；风格：黑色幽默；情节：……”；也支持“请帮我写个故事”等礼貌前缀。没有素材时会随机选主题，有素材时用素材首句作为主题；未指定风格时随机选择。自定义风格最多 20 字，用分号隔开后续情节；主题最多 80 字、素材最多 800 字、整条输入最多 1000 字。微信私聊可直接发送。消息开头是故事命令或礼貌前缀加故事命令时才触发；否定命令和“随机故事是什么”一类讨论句不会生成故事，素材里的否定内容仍作为故事要求保留。含有“不用”“别”等否定的说法不会变成开启或发送命令。

`/图鉴`、`/角色图鉴` 是空参数图鉴总览命令；`/角色图鉴 捷德` 保留查询参数，交给 `extract_catalog_lookup` 处理。猫图示例对应主路由的 `CAT_IMAGE_COMMANDS`；翻唱例子由 `parse_singing_command` 解析。普通帮助命令发送图片，文字菜单请求优先发送分组文字菜单。
