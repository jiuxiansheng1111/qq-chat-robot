# 从 QQ 使用网页、电脑和家里的设备

## 实际能操作什么

| 对象 | 主人私聊里的用法 | 连接 |
| --- | --- | --- |
| 网页 | 「打开网页 https://example.org」「网页往下翻」「点击详情」「在网页的搜索框里输入鲸鱼」「总结当前网页」「问网页：活动到哪天？」 | 大肥鱼打开独立浏览器，空闲十分钟关闭。点名跨站链接后会打开对应公网网站。总结和问答使用所选聊天模型及已经读取的网页正文。 |
| 这台 Windows 电脑 | 「在电脑上打开计算器」「电脑当前窗口是什么」「让电脑切到下一首」「让电脑锁屏」 | 使用本机 Windows。查看窗口标题需要机器人运行在已登录用户的桌面。 |
| 蓝牙灯、插座 | 「打开卧室灯」「把卧室灯调到50%」「卧室灯开着吗」 | 在 Home Assistant 配对型号支持的 Bluetooth 集成。灯和开关会读取实际实体状态。 |
| 空调 | 「把书房空调调到26度」 | 需要能在 Home Assistant 中设置温度的 climate 实体。传统红外遥控需匹配的红外网关；只支持发码的设备可绑定为 script，通过实体传感器才能再核对实际温度或开关。 |
| 灯光与音乐 | 「执行阅读场景」「把音箱音量设为20%」「暂停卧室音箱」 | 可绑定一个灯光与音乐联动的 scene 或 script，也可分别绑定灯和 media_player。 |
| 另一台电脑 | 「按一下电脑开机」 | 为启用网络唤醒的电脑绑定 Wake on LAN 按钮，也可用 HASS.Agent 把 Windows 动作发布给 Home Assistant。 |
| 手机 | 「执行手机响铃」 | 在 Home Assistant Companion App 授权相应的通知命令，再绑定对应的脚本。Android 和 iOS 支持的动作不同。 |

打开本机账号页「家里的设备」，填写 Home Assistant 地址和长期访问令牌，验证后读取设备。选一个实体，给它取聊天时用的名字，例如「卧室灯」。在页面里可以逐个解除绑定或断开整套连接。发送一次按钮指令收到 QQ 重投时只执行一次。场景、红外或按钮缺少传感器回报时，大肥鱼只报告指令已被接收。

蓝牙连接由 Home Assistant 主机的适配器或家庭蓝牙代理建立。大肥鱼在手机上时，经家庭网络向它下指令。灯带可先核对 LED BLE 集成支持的型号；空调使用红外遥控时要有匹配的红外网关。设备只返回推测状态时，回复里会标明「控制器估计」。[Home Assistant Bluetooth](https://www.home-assistant.io/integrations/bluetooth/) · [LED BLE](https://www.home-assistant.io/integrations/led_ble/) · [ESPHome 蓝牙代理](https://esphome.io/components/bluetooth_proxy/)

项目直接复用 Playwright 的独立浏览器会话和 Home Assistant 的 REST API。桌面动作由 Windows 提供。支持哪些硬件取决于已配对的集成。[Playwright Python](https://github.com/microsoft/playwright-python) · [Home Assistant REST API](https://developers.home-assistant.io/docs/api/rest/) · [SwitchBot Bluetooth](https://www.home-assistant.io/integrations/switchbot/) · [Broadlink 红外](https://www.home-assistant.io/integrations/broadlink/) · [Wake on LAN](https://www.home-assistant.io/integrations/wake_on_lan/) · [HASS.Agent](https://github.com/hass-agent/HASS.Agent) · [手机通知命令](https://companion.home-assistant.io/docs/notifications/notification-commands/)

## 用手机当服务器

Android 可以通过 Termux 和 Ubuntu 用户空间运行 AstrBot。脚本按本项目验收的 AstrBot 4.28.2 和 Python 3.12 准备独立实例。Termux 与 Termux:Boot 从同一发行渠道安装，分别打开一次。把仓库中的启动脚本存到 Termux 后运行以下命令。[Termux:Boot](https://github.com/termux/termux-boot) · [PRoot-Distro](https://github.com/termux/proot-distro) · [AstrBot 安装](https://docs.astrbot.app/deploy/astrbot/package.html)

```sh
bash termux-dafeiyu.sh prepare
bash termux-dafeiyu.sh password
bash termux-dafeiyu.sh browser
bash termux-dafeiyu.sh run
```

`password` 在本机为管理账号 `admin` 设置登录密码，输入时屏幕不回显。运行中的实例会占用独立锁，手动启动和开机启动可以共用同一份配置。

手机本机打开 [大肥鱼网页助手](http://127.0.0.1:6190/accounts)，在「网页助手」里直接输入网站地址，再点「下一屏」，或输入「点击详情」。每个标签页各自保留网页十分钟。首次安装浏览器会下载 Chromium 和中文字体，脚本会启动浏览器并检查能否读取中文。仅做 QQ 聊天时可跳过 `browser`。[Playwright 浏览器安装](https://playwright.dev/python/docs/browsers)

也可以先在同一页的「聊天和网页助手的模型」连接模型，再打开网页说「问网页：活动到哪天？」。手机还没连 QQ 时也可以使用。手机 AstrBot 面板内普通 WebChat 对话也使用这里选的模型。Ollama 从服务读取模型能力；其他服务可按实际模型选择「纯文字」「文字和看图」或工具调用。手机上的 `127.0.0.1` 指手机自己。如果希望电脑关机后继续聊天，请选手机能直接连接的云端服务或手机本机模型。

要从 QQ 私聊控制自己的设备，在 Termux 执行 `bash termux-dafeiyu.sh owner 你的QQ号`。初次登记只启用主人识别，聊天存档默认关闭。

要直接控制运行大肥鱼的安卓手机，从安装 Termux 的同一发行渠道安装 Termux:API，然后执行 `bash termux-dafeiyu.sh phone`。命令会从机器人所在的 Ubuntu 环境读取一次手机的真实电量。随后主人可以私聊说「手机还剩多少电」「让手机振动一下」「打开手机手电筒」或「关闭手机手电筒」。手电筒需要 Android 授予相机权限。手机动作也可以独立安装「安卓手机助手」分件。[Termux:API](https://github.com/termux/termux-api) · [PRoot-Distro 的 Termux 工具访问](https://github.com/termux/proot-distro#host-bindings-termux-default-mode)

手机浏览器打开本机的 `http://127.0.0.1:6185` 进入 AstrBot。网页助手可独立运行。要接原来的 QQ 号，还需要一个已登录的 OneBot V11 协议端。2026 年 11 月 17 日核查时，NapCat 官方主仓库只留下结束说明，原官方安卓安装仓库已返回 404。已有的 Windows NapCat 可以继续连接手机。要关掉电脑，QQ 协议端也得迁到能够持续在线的设备，手机单机 QQ 仍需用自己的登录环境验证。[NapCat 官方仓库](https://github.com/NapNeko/NapCatQQ)

若要把现有 NapCat 接到手机，在启动手机实例前执行 `bash termux-dafeiyu.sh onebot 手机的局域网或私有VPN地址`。再用 `bash termux-dafeiyu.sh pairing` 在手机终端查看地址和令牌，把两项填进 NapCat 的反向 WebSocket 客户端。完成迁移时切换原连接，以免两个实例同时回复。若协议端就在同一台手机，`onebot` 可不填写地址。账号页的「检查 QQ 连接」会向已经连入的协议端查询登录与在线状态。

手动启动成功后，另开一个 Termux 会话执行 `bash termux-dafeiyu.sh status`，再用 `bash termux-dafeiyu.sh enable-boot` 启用重启后的自启动。关闭手动实例后重启手机并解锁一次。在系统设置允许 Termux 后台运行，再分别测试熄屏、Wi-Fi 重连和重启后的网页与 QQ 收发。Android 的省电模式可能推迟后台联网，网页能打开只说明面板在线。Windows 桌面动作需要一台在线的 Windows 电脑，本机 Ollama 需要让手机实际能访问模型服务。[Android 后台与 Doze](https://developer.android.com/training/monitoring-device-state/doze-standby)

iPhone 可以用 QQ 和在线的大肥鱼对话，也能通过自己的私有网络访问常开主机上的 AstrBot WebChat。需要从手机浏览器访问时，可给有登录保护的 AstrBot 配置 Tailscale Serve。本机账号管理页仅接受回环访问。iOS 的后台执行由系统调度，普通应用无法持续运行常驻服务。[Apple 后台执行说明](https://developer.apple.com/forums/thread/685525) · [Tailscale Serve](https://tailscale.com/docs/reference/tailscale-cli/serve)
