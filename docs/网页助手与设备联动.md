# 从 QQ 使用网页、电脑和家里的设备

## 实际能操作什么

| 对象 | 主人私聊里的用法 | 连接 |
| --- | --- | --- |
| 网页 | 「打开网页 https://example.org」「网页往下翻」「点击详情」「在网页的搜索框里输入鲸鱼」 | 大肥鱼打开独立浏览器。每次打开一个公网网站，沿用当前页面，空闲十分钟关闭。跨站链接可以发一个新地址。 |
| 这台 Windows 电脑 | 「在电脑上打开计算器」「电脑当前窗口是什么」「让电脑切到下一首」「让电脑锁屏」 | 使用本机 Windows。查看窗口标题需要机器人运行在已登录用户的桌面。 |
| 蓝牙灯、插座 | 「打开卧室灯」「把卧室灯调到50%」「卧室灯开着吗」 | 在 Home Assistant 配对型号支持的 Bluetooth 集成。灯和开关会读取实际实体状态。 |
| 空调 | 「把书房空调调到26度」 | 需要能在 Home Assistant 中设置温度的 climate 实体。传统红外遥控需匹配的红外网关；只支持发码的设备可绑定为 script，通过实体传感器才能再核对实际温度或开关。 |
| 灯光与音乐 | 「执行阅读场景」「把音箱音量设为20%」「暂停卧室音箱」 | 可绑定一个灯光与音乐联动的 scene 或 script，也可分别绑定灯和 media_player。 |
| 另一台电脑 | 「按一下电脑开机」 | 为启用网络唤醒的电脑绑定 Wake on LAN 按钮，也可用 HASS.Agent 把 Windows 动作发布给 Home Assistant。 |
| 手机 | 「执行手机响铃」 | 在 Home Assistant Companion App 授权相应的通知命令，再绑定对应的脚本。Android 和 iOS 支持的动作不同。 |

打开本机账号页「家里的设备」，填写 Home Assistant 地址和长期访问令牌，验证后读取设备。选一个实体，给它取聊天时用的名字，例如「卧室灯」。在页面里可以逐个解除绑定或断开整套连接。发送一次按钮指令收到 QQ 重投时只执行一次。场景、红外或按钮缺少传感器回报时，大肥鱼只报告指令已被接收。

项目直接复用 Playwright 的独立浏览器会话和 Home Assistant 的 REST API。桌面动作由 Windows 提供。支持哪些硬件取决于已配对的集成。[Playwright Python](https://github.com/microsoft/playwright-python) · [Home Assistant REST API](https://developers.home-assistant.io/docs/api/rest/) · [SwitchBot Bluetooth](https://www.home-assistant.io/integrations/switchbot/) · [Broadlink 红外](https://www.home-assistant.io/integrations/broadlink/) · [Wake on LAN](https://www.home-assistant.io/integrations/wake_on_lan/) · [HASS.Agent](https://github.com/hass-agent/HASS.Agent) · [手机通知命令](https://companion.home-assistant.io/docs/notifications/notification-commands/)

## 用手机当服务器

Android 可以通过 Termux 和 Ubuntu 用户空间运行 AstrBot。脚本按本项目验收的 AstrBot 4.28.2 和 Python 3.12 准备独立实例。Termux 与 Termux:Boot 从同一发行渠道安装，分别打开一次。把仓库中的启动脚本存到 Termux 后运行以下命令。[Termux:Boot](https://github.com/termux/termux-boot) · [PRoot-Distro](https://github.com/termux/proot-distro) · [AstrBot 安装](https://docs.astrbot.app/deploy/astrbot/package.html)

```sh
bash termux-dafeiyu.sh prepare
bash termux-dafeiyu.sh run
```

手机浏览器打开本机的 `http://127.0.0.1:6185` 进入 AstrBot，完成面板登录，选择聊天服务。连接 QQ 时还要有已登录的 NapCat 和 OneBot 反向 WebSocket。QQ 在电脑上登录时，NapCat 要连到手机在两端互通的私有网络地址；把两套服务都放手机上才可以关掉电脑。NapCat 的 Android 安装路径单独按官方说明准备。原部署的 `127.0.0.1:6199` 在手机上指向手机自己。[NapCat 安装文档](https://napneko.github.io/guide/install)

手动启动成功后，另开一个 Termux 会话执行 `bash termux-dafeiyu.sh status`，再用 `bash termux-dafeiyu.sh enable-boot` 启用重启后的自启动。关闭手动实例后重启手机并解锁一次。在系统设置允许 Termux 后台运行，再分别测试熄屏、Wi-Fi 重连和重启后的网页与 QQ 收发。Android 的省电模式可能推迟后台联网，网页能打开只说明面板在线。Windows 桌面动作需要一台在线的 Windows 电脑，本机 Ollama 需要让手机实际能访问模型服务。[Android 后台与 Doze](https://developer.android.com/training/monitoring-device-state/doze-standby)

iPhone 可以用浏览器访问运行在电脑、安卓机或服务器上的 AstrBot。iOS 的普通应用没有一直在后台运行任意服务的机制，全天候 QQ 主机应选用能维持后台进程的设备。[Apple 后台执行说明](https://developer.apple.com/forums/thread/685525)
