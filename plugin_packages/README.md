# 大肥鱼插件下载

分件版 v0.5.0，适用于 AstrBot 4.28.2。点表格里的 **下载 ZIP** 可以直接取得单个安装包。

## 安装

1. 下载并安装第一批里的**共享运行时**。在 AstrBot 管理面板的「插件」页选择「从文件安装」，上传 ZIP 并启用。
2. 在下表选需要的功能，用同样的方法分别安装。例如只想在群里查炉石卡牌，装「共享运行时」和「炉石查卡」两个包即可。
3. QQ 群里需要按昵称接话或参与游戏时，在共享运行时配置的「接话与自然命令的 QQ 群名单」中填入目标群。在会话插件白名单中同时启用共享运行时和所需功能。天气、翻译、点歌、炉石查卡、约定回访和 Steam 邀请也支持 QQ 私聊。
4. 已装整合版的用户，先备份旧配置，停用整合版并重启 AstrBot，再启用这些分件；每个功能可在面板中单独启停。更新时从本页下载同一版本的 ZIP，保留插件数据目录。

共享运行时保管共同的连接、数据库和配置，功能插件提供独立的消息处理入口。可选安装「功能菜单」，聊天时说“肥鱼菜单”可查看当前会话启用了哪些功能。[AstrBot 安装说明](https://docs.astrbot.app/use/plugin.html)

## 账号、模型和本机组件

- 共享运行时的数据在 AstrBot 的 `data/plugin_data/astrbot_plugin_qqchat_core/` 下；项目配置文件 `.env`、数据库和登录文件由部署者保存在这里。原整合版的数据可先备份，再按用到的模块迁移。
- 需要管理账号时安装「本机账号管理」，在运行机器上打开 `http://127.0.0.1:6190/`。Steam 联机需要本机的专用 Steam 账号；Minecraft 需要 Java 服务器。Minecraft 玩家使用 Node.js 22 或以上，在共享运行时数据目录的 `integrations/minecraft-player/` 执行 `npm ci`。[多人游戏陪伴](../docs/多人游戏陪伴.md)
- 图片理解需要在 AstrBot 配置支持图像的模型。生图、语音、翻唱和音频分析使用各自配置的服务或本机模型。需要分析“一起听”的真实声音时，同时安装「音频分析」并配置 SoundTry。网易云实时消息桥的安装步骤见[桥接组件说明](../integrations/netease/realtime/README.md)。
- 炉石查卡可以单装；要查卡组强度和胜率再装「炉石卡组与约战」；要比较三选一并记录已选牌，再装「炉石竞技场」。

## 文件校验与构建

每个 ZIP 的 SHA-256 指纹都在[校验清单](downloads/SHA256SUMS)中。在仓库根目录运行 `python scripts/package_plugins.py` 可重新构建全部安装包，加上 `--check` 可核对现有安装包和源码。在装有 AstrBot 4.28.2 的 Python 环境运行 `python scripts/verify_plugin_packages.py` 可从空目录验证安装、消息分发和卸载。
