# 网易云账号桥与 QQ 陪听

复用本项目此前为音乐功能接入的网易云账号和本机 SDK，不另建账号系统，不读取其他应用凭据。Cookie 留在本机桥内，QQ 工具只拿到本次歌曲音源或必要的房间状态。

QQ 工具 `qqchat_listen_music` 可以按歌名、歌曲编号或网易云官方链接听取完整可播放音轨。复用原歌曲匹配、账号权限、完整性及官方 CDN 检查；拿不到完整音源就回复失败，不冒充已经听过。SoundTry 在后台分析，当前 Luna 模型以大肥鱼人格给出听感，期间能继续聊天。

收到本轮或引用中的有效一起听邀请时，工具调用本地 `/api/listen` 接受邀请并核对网易云返回的房间身份；未确认时不能说已加入。确认后后台轮询、发送心跳、尝试读取当前曲目并听取。平台若不提供当前曲目或断线，就如实回复。停止陪听时停止自己的连接，不调用会关闭所有人房间的 `end` 接口。真实房间加入需用有效邀请联调。

`qqchat_music_artist` 从网易云公开元信息核对歌手名、别名、中文名及日文名，无法确定时让聊天模型继续联网查证；重名候选不等于同一个人。

用户明确授权的歌曲记忆保存在原 `data/qqchat.db` 的 `music_listens` 表，按会话与用户隔离，记录真实听取证据、时间、次数与感受，不写入凭据或可过期音源 URL，不恢复自动画像和闲聊学习。
